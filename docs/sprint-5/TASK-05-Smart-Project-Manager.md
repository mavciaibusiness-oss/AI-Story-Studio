# Sprint-5 / TASK-05 — Smart Project Manager

Creator OS artık projeleri klasör mantığıyla değil, akıllı şekilde yönetmelidir.

---

# Amaç

Project Manager;

kullanıcının bütün çalışmalarını

tek merkezden yönetecek.

Proje oluşturmak,

devam etmek,

arşivlemek,

karşılaştırmak,

geri almak,

AI tarafından önerilmek

tek sistem altında çalışacak.

---

# Smart Projects

Her proje;

- isim
- tip
- kategori
- hedef platform
- durum
- oluşturma tarihi
- son düzenleme
- AI Director özeti
- Creator Memory bağlantısı

taşımalıdır.
